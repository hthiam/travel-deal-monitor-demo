# ✈️ Travel Deal Monitor

A Python web application for searching and comparing accommodation prices from Booking.com and Airbnb.

This project was developed as part of my Python web scraping and automation portfolio.

## 🎥 Project Demo

▶️ [Watch the Travel Deal Monitor demo](demo/travel-deal-monitor-demo.mp4)

The demo shows the application performing a real accommodation search and displaying the results through its web interface.

## 🚀 Features

- 🔎 Search accommodations by destination
- 🏨 Booking.com and Airbnb search
- 📅 Check-in and check-out date selection
- 👥 Number of travelers
- 🌍 Automatic country detection
- 💰 Accommodation price extraction
- 📊 Results sorted from cheapest to most expensive
- 🏆 Display of the 20 cheapest results found
- ⭐ Hotel star ratings when available
- 📝 Customer review scores
- 🔗 Direct link to the accommodation page

## 🛠️ Technologies

- Python
- Flask
- Playwright
- Geopy
- Regular Expressions (Regex)
- HTML
- CSS

## 💡 Project Purpose

Travel Deal Monitor demonstrates how Python and browser automation can be used to collect, process and present accommodation data through a simple web interface.

The project combines web scraping, data processing and web development.
